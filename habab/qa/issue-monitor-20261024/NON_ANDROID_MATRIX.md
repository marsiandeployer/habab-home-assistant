# Non-Android acceptance matrix: assistant chat and Home Assistant actions

Prepared 2026-10-24 from the local issue snapshot, product docs, source contracts, and existing QA artifacts. This is a finite test map for implemented non-Android chat capabilities; it does not claim all Home Assistant integrations, devices, or radio paths have been tested.

## Runtime and evidence rules

- Acceptance target supplied for this task: owner-test **Habab Home 0.3.4 v15 / source `a3c1d3f06`**. Verify the installed image and source before each live run. Workspace candidates `3b0` / `339` are not this deployed runtime.
- The local evidence folder contains multiple older generations: isolated 0.2.0, 0.3.0, 0.3.1, Xiaomi image checks, and owner candidates v8/v14. Their results remain historical unless the artifact itself binds the test to v15/a3c1.
- A model response, unit test, browser render, tool trace, API result, and independent Home Assistant readback prove different things. For any state-changing claim require a fresh readback after the reply; record a narrowly scoped cleanup/restoration.
- Do not include device/user IDs, live chat text, OAuth data, tokens, private login paths, or raw transcripts in the evidence artifact.
- Issue #12 (shopping-list E2E), #13 (provider UI), and cloud Gateway release are owned in the parent session. Do not duplicate their execution. Exclude Android files, builds, tunnels, and physical-device work from this matrix.
