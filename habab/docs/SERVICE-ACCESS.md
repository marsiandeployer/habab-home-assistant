# Провайдер Habab

В исходном кандидате 0.3.3 провайдер выбирается в разделе AI. Успешное действие
«Проверить и сохранить» выбирает подключение для веб-чата и Telegram. Сохранённые
подключения других провайдеров остаются на месте.

| Выбор | Адрес API |
|---|---|
| Habab | `https://habab-voice.wpmix.net/v1` |
| OpenAI | `https://api.openai.com/v1` |
| DeepSeek | `https://api.deepseek.com` |
| Google Gemini | `https://generativelanguage.googleapis.com/v1beta/openai` |

Для Habab нужен отдельный сервисный ключ от администратора. Ключ OpenAI или
DeepSeek в этом поле не подходит. Автоматическая выдача ключей и биллинг пока
не подключены. Проверка связи должна пройти до сохранения подключения.

Команды выполняются локальным Home Assistant через общий сервис помощника.
При выборе Habab обращения к модели идут на сервер Habab. Фоновый Realtime
поддерживает Habab и OpenAI: у Habab HTTPS/WSS идут через наш сервер, у OpenAI —
напрямую. Если выбранный провайдер не поддерживает Realtime, возвращается явная
ошибка, без использования ключа другого сохранённого подключения.

Сервер хранит SHA-256 сервисного ключа. Операторский ключ OpenAI загружается через
закрытый UNIX-сокет и используется в оперативной памяти. После перезапуска
сервера его нужно загрузить снова; до этого API сообщает о недоступности.
Ключ Habab не пересылается в OpenAI. Пароли подключаемых устройств вводятся
в защищённых формах Home Assistant.

Telegram использует собственный токен BotFather и прямой Bot API. Для сети,
где Telegram недоступен, в локальных настройках можно указать HTTP/HTTPS-прокси.
Выбор Habab как ИИ-провайдера не меняет этот маршрут Telegram. Временный USB-
канал проверки P30 закрыт после тестов и не обеспечивает постоянное подключение.

Объём фактических проверок и ограничения записаны в
[отчёте P30](../android/qa/voice/habab-0.3.3-phone.json). Правомерность сервисной
схемы вынесена в отдельную [задачу №11](https://github.com/marsiandeployer/habab-home-assistant/issues/11)
по просьбе пользователя; эта инструкция не является юридическим заключением.
