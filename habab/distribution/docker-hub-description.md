# Habab Home

Habab Home — бета-сборка Home Assistant с чатом настройки и интеграциями Habab.
Docker-образ предназначен для Linux AMD64 и ARM64. OpenCode и интерфейс Habab
включены в образ; устанавливать OpenCode на хост отдельно не нужно.

- [Сайт и загрузки](https://habab.ru/home-assistant)
- [Установка Docker-образа](https://habab.ru/habab-docker-install)
- [Исходный код](https://github.com/marsiandeployer/habab-home-assistant)
- [Поддержка](https://t.me/onoutnoxon)

## Установка

Выберите опубликованный версионный тег на вкладке **Tags**. До появления первого
тега образ проходит сборку и проверку.

```sh
docker pull hababer/habab-home:<versioned-tag>
```

Compose-файл, первый запуск, доступ из домашней сети и команды обновления
описаны в [инструкции](https://habab.ru/habab-docker-install).
Постоянные настройки Home Assistant нужно хранить в отдельном томе `/config`.
При первом открытии создайте собственную учётную запись владельца.

Для ответов помощника выберите провайдера в разделе AI своей установки.
Ключи и языковая модель в образ не входят. Голосовые сервисы настраиваются
отдельно. Образ содержит Home Assistant Core; Home Assistant OS, Supervisor
и магазин дополнений в него не входят.

Перед обновлением сохраните резервную копию `/config` и предыдущий тег образа.
Смена тега приложения не отменяет миграции базы данных.
