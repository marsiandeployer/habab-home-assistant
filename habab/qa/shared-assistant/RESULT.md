# Единый чат Habab Home 0.3.1

Один исходный компонент работает в обычной демо-странице, прежнем onboarding URL и после входа администратора Home Assistant. Разделы AI и штатный вызов Assist открывают ту же панель. Публичное демо отвечает текстом без инструментов; приватный чат сохраняет действующие права администратора.

Чат открывается при первой авторизованной загрузке на любой странице. Закрытие пользователем сохраняется при переходах в текущем приложении; кнопка справа снизу открывает его снова. На компьютере панель занимает правую половину страницы. На мобильном дашборд занимает верхнюю половину, чат — нижнюю; фокус в поле ввода разворачивает чат на доступную высоту. Сворачивание возвращает дашборд и сохраняет черновик. Блок «Дом сейчас» и его отдельная загрузка состояний удалены.

- Чистая сборка образа прошла; pinned Node обновлён до доступного `24.22.1-r0`. Собранный образ проверен без source overlays: страницы обзора, настроек и AI; desktop, mobile, разворачивание, сворачивание, сохранение черновика, закрытие и повторное открытие.
- Оба браузерных отчёта: `PASS_WITH_LIMITS`, ошибок JavaScript нет. В приватном Core зафиксированы прерванные запросы нативных шрифтов; отдельной ошибки страницы они не дали.
- 105 Python tests в собранном образе, 30 JS tests, 8 lifecycle tests под Node образа, 5 Telegram transport tests под Node образа, 3 теста общего publisher — прошли. Пять реальных публичных ответов модели получены и прочитаны; ложных утверждений о подключении устройств не обнаружено.

## Как потестить

Открыть `https://habab-demo.wpmix.net/`: чат появляется справа. На телефоне или viewport 390×844 он появляется снизу; нажатие поля ввода разворачивает чат, стрелка вниз возвращает панель дома. В установленном Habab Home 0.3.1 войти администратором и проверить те же действия в обзоре, настройках и AI.

Команды: `node --test habab/distribution/tests/*.mjs`; `python3 -m unittest discover -s habab/build -p 'test_assistant_bundle.py'`. Браузерный сценарий: `node habab/qa/shared-assistant/check-ui.cjs` с уже работающим локальным CDP на порту 9222. Приватный режим требует отдельной QA-среды, не пользовательского дома.

Windows-пакет: `https://habab-demo.wpmix.net/downloads/habab-home-windows-dcfbe4740bb6.zip`, SHA-256 `dcfbe4740bb6f39044bd14c66a449a7b02d626a28f6405990cc301161748825f`. После распаковки запускать `start-windows.bat`; из Git checkout — `habab\distribution\start-windows.bat`. Пакет содержит только принятый DeepSeek runtime; параллельная работа над Android Realtime/OpenAI в него не входит. Контрольная сумма тела опубликованного ZIP проверена.
