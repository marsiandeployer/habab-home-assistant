# Habab Home

Продукт: локальный домашний сервер на Linux и Docker, с русским Home Assistant; необязательные облачные функции включаются владельцем. Связь с устройствами проходит по LAN/Wi-Fi и, при наличии координатора, Zigbee.

Публичная демонстрация показывает виртуальные устройства и хранит состояние отдельно для посетителя. Она не подключена к реальному дому или приватному Core. Настоящий Docker-дистрибутив и демонстрационный frontend имеют разные серверные границы.

Текущий запрос: раздел подключений OpenAI, DeepSeek и Google Gemini с инструкциями, проверкой API и выполнением голосовых команд. В Docker-дистрибутиве интеграция habab_home добавляет административную панель /habab-ai и нативные агенты Assist. OpenAI предоставляет также STT/TTS; DeepSeek и Gemini используют выбранные речевые движки Assist. VAD выполняется в Home Assistant. Публичное демо сохраняет отдельную границу виртуальных устройств.

Дополнительно: минимальный чат настройки OpenCode + DeepSeek открывается иконкой перед «+». Домашний администратор может выполнять команды внутри Docker, смотреть состояния и настраивать интеграции через штатные API HA. Общий с хостом только исполняемый файл OpenCode через read-only mount; настройки и история отдельные. Публичный чат отвечает через DeepSeek без инструментов и доступа к дому. Windows-батник устанавливает недостающее ПО и запускает отдельную локальную установку без заранее заданных ключей и аккаунтов.

Критерий успеха: реальный API выбранного провайдера вызывает инструмент Assist, состояние разрешённого устройства меняется и проверяется; голосовой путь проходит VAD, STT, действие и TTS. Ключи сохраняются в локальных config entries Home Assistant, не включаются в frontend-ответы и артефакты. Скрытые и отсутствующие устройства не должны подменяться доступным устройством. Синтетический микрофон в браузере не доказывает качество физического микрофона или работу на iOS.

Для формы критерий успеха: посетитель открывает настройку, вводит токен, видит результат в демо и понимает, что настоящий бот не запущен. Токен не покидает поле, не сохраняется и очищается при завершении/закрытии. В форме предусмотрены валидация, скрытие/показ токена, отмена и доступ с клавиатуры.

Визуальный мир уже задан Home Assistant: рабочий интерфейс, знакомая структура, Roboto, светлая нейтральная поверхность и синий акцент. Новый бренд или redesign не запрошен; добавление сохраняет существующий мир.
