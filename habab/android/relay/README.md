# API-шлюз для Android

Небольшой отдельный сервис пересылает запросы OpenAI и Telegram с авторизацией.
Он не подключается к Home Assistant, не выбирает модели и не получает историю
из публичного демо. Нужен при недоступности прямого API с телефона.

В приватном JSON за пределами репозитория хранить только `key_sha256`
(SHA-256 разрешённого OpenAI ключа), при необходимости `telegram_sha256`
(SHA-256 отдельного токена бота) и `port`. Права каталога — 0700, файла — 0600.
Сами ключи приходят только в заголовке Authorization по TLS. Сервис передаёт
их провайдеру, не сохраняет и не пишет в журнал. Доступ к серверу и его
администраторам означает доверие обработке этих запросов и аудио.

Зависимости: `requirements.txt`. Запуск через `ecosystem.config.cjs` с отдельным
venv; приложение слушает только loopback. `nginx.conf` — внутренний reverse
proxy, `nginx-edge.conf` — TLS edge. Перед применением изменить адреса и пути
под свою инфраструктуру и проверить `nginx -t`. Access log выключен на обоих
уровнях; не включать дамп заголовков, тела и WebSocket кадров.

Android передаёт Core явно выбранные `HABAB_OPENAI_BASE_URL` (HTTPS, путь `/v1`)
и `HABAB_TELEGRAM_RELAY` (корневой HTTPS URL). Без этих настроек используется
прямой транспорт. Telegram getUpdates запускает только бот на телефоне;
второй poller на шлюзе не создаётся. `/health` публичен; API отвергает
неизвестные ключи. Пересылка Telegram ограничена getMe, getUpdates,
sendMessage, sendChatAction, getWebhookInfo. Шлюз не меняет webhook.

Голосовая сессия получает временный ключ через Core, а не постоянный ключ
OpenAI в Android-службу. Шлюз хранит хеш временного ключа до 60 секунд,
привязывает его к модели и погашает при первом подключении. Лимиты: два
голосовых соединения, 180 секунд и 16 MiB в каждую сторону; шесть параллельных
HTTP запросов, 2 MiB входящего и 8 MiB ответного тела.

Проверки без реальных ключей:

```sh
python -m unittest discover -s habab/android/relay -p test_gateway.py -v
```

Текущая установка: `habab-voice-relay`, loopback 8326, отдельный TLS hostname
`habab-voice.wpmix.net`. Приватный конфиг и venv являются активными
зависимостями сервиса; их нельзя удалять как временные файлы сборки.
