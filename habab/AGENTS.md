# Компоненты Habab

Читайте README.md и docs/UPDATING.md. Корневой AGENTS.md описывает upstream TypeScript/Lit. Этот подкаталог содержит отдельный Flask API, Docker-пакет и независимые browser-дополнения. public/integrations/ — компоненты без зависимости от внутренних скомпилированных модулей HA.

- Демо управляет только виртуальными устройствами. Не подключать его к реальному дому, USB или приватному Core.
- Секреты, .env, production-логи и данные пользователей не коммитить, не выводить и не отправлять в аналитику. В демо-форме Telegram токен не должен покидать поле ввода или сохраняться.
- Процессы управляются PM2. Не перезапускать сайт Habab ради демо.
- Состояние хранится в PostgreSQL. При совместимых обновлениях сохранять ключ сессии, таблицы и тома.
- public/releases/ и compiler output генерируются сборкой; не редактировать минифицированные чанки вручную.
- Сборки используют исходники fork в корневых demo/, src/, build-scripts/. Архив patch не накладывать повторно.
- Проверять API и фактическое поведение desktop/mobile; микрофон включать по действию пользователя. Эмуляция не является проверкой физического микрофона/iOS.
- Голосовой Assist и провайдеры домашней установки реализованы в distribution/src/habab_home; настройки и ключи принадлежат нативным config entries Home Assistant. Публичное демо к ним не подключать. Проверенный объём и QA-команды — docs/VOICE.md.
- Чат настройки использует отдельный приватный процесс OpenCode внутри HA. Общий с хостом только musl-бинарник через read-only mount, без host HOME/ключей/истории или Docker socket. Инструкция — docs/SETUP-ASSISTANT.md; Bluetooth override явно разрешает доступ к BlueZ хоста.
- Реальный Telegram-бот, локальная речь, Яндекс и физическое железо требуют отдельной сквозной проверки. Синтетическое аудио и виртуальная сущность не доказывают аппаратную работу.
- Физические проверки, которые двигают устройства или создают шум (например, пылесос, сирена или TTS), проводите только днём по местному времени дома. Если местное время в доме неизвестно или нельзя подтвердить, что сейчас день, отложите такую проверку. Ночью допускаются только проверки исходников и серверных компонентов, которые не запускают устройства. Для остановки уже работающего устройства или приведения его в безопасное состояние допустима безопасная очистка; новый цикл не запускать.
